# BrightCare Health Plans

A simple health insurance website. It includes plan options, support details, an about section, and a contact form powered by Web3Forms.

## Files

- `index.html` - main landing page
- `styles.css` - responsive styling

## Open The Website

Open `index.html` in your browser.

The contact form submits directly to Web3Forms using the access key in `index.html`.

## Customize

Update the text, colors, and branding to match your insurance business.
